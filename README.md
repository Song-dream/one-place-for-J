# 我的工作台 · 个人生活管理系统

一个**单文件**的个人工作台：不用安装、不用注册、不用服务器，双击 `index.html` 就能在浏览器里使用。所有数据保存在你自己的浏览器本地（localStorage），不上传到任何服务器。

**在线体验**：https://song-dream.github.io/one-place-for-J/

> 在线演示模式：打开 `index.html?demo=1`（可加 `&view=finance` 等参数直达某个页面）。演示模式完全隔离，不会写入任何真实数据。

## 快速开始

**方式一：本地使用（推荐先试这个）**

1. 下载本仓库（Code → Download ZIP，或 `git clone`）
2. 双击 `index.html`，在浏览器中打开即可
3. 左下角「载入示例数据」可以先用示例数据体验；「清除所有数据」可一键重置

**方式二：部署到 GitHub Pages，得到一个在线版（手机、平板也能用）**

1. 把仓库推送到你的 GitHub 仓库
2. 仓库 → Settings → Pages → Source 选 `main` 分支 / root 目录 → Save
3. 稍等 1-2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

**在手机 / 平板上使用**

本地 HTML 文件在 iOS 上很难直接打开，推荐用 Pages 链接：

1. 用 Safari / Chrome 打开上面的 Pages 地址
2. iOS Safari：点「分享」→「添加到主屏幕」；Android Chrome：菜单 →「添加到主屏幕」
3. 之后像 App 一样从桌面图标打开

> 注意：电脑和手机的数据是**各自独立**的（存在各自浏览器里）。手机端想接着用电脑的数据，请先在电脑上「导出数据」，把 JSON 传到手机，再用手机端「导入数据」。

**常见问题**

| 现象 | 原因与处理 |
|---|---|
| 打开后变成一堆代码 / 直接下载了文件 | 直接把 zip 里的 html 双击了。请先**解压**，再双击解压出来的 `index.html` |
| 打开是空白页 | 浏览器太旧（建议 Chrome / Edge / Safari 近两年版本），或文件被安全软件拦截 |
| 卡在登录 / 要邮箱验证码 | 你拿到的是带云同步的原版，不是本仓库的独立版 |
| 换电脑后数据没了 | 数据存在原浏览器的 localStorage 里，用「导出 / 导入数据」迁移 |
| 数据突然全空 | 清过浏览器缓存、用了无痕模式，或换了域名/端口访问（同源策略不同） |

## 数据存储与隐私

- 所有数据保存在**当前浏览器的 localStorage** 中，与设备、浏览器绑定
- 换浏览器或换设备不会自动同步；请定期用左下角 **「导出数据」** 导出 JSON 备份，需要时用 **「导入数据」** 恢复
- 清除浏览器数据 / 无痕模式会导致数据丢失，请注意备份
- 本项目不含任何统计、埋点或网络请求，完全离线可用

## 想要多设备同步？

本开源版是纯本地版。原版的云同步基于 WorkBuddy 云服务（登录 + 云数据库），因为包含作者的私有后端配置，故未包含在此仓库中。如果你需要同步能力，可以：

- 自行接入任意后端（Supabase / Firebase 等），修改 `index.html` 中 `CLOUD_CONFIG` 附近的云服务逻辑（源码内已有完整的读写、防覆盖、行去重实现可供参考）
- 或者简单地用「导出数据 → 换设备 → 导入数据」手动迁移

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无构建工具、无框架、无依赖
- 状态集中在 `state` 对象，视图按 `currentView` 分发渲染，事件统一委托
- 所有可视化（图表、热力图、环形图）均为手写 SVG / CSS
- 图片粘贴上传前会在本地 canvas 压缩，不会产生任何上传流量
